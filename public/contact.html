Corrections, bugs, and privacy questions

PatternGuru is maintained by one person, Mukesh Singh Negi, so the fastest route for anything is GitHub — it is checked regularly and keeps the discussion attached to the code.

Report a problem or suggest a change

Open an issue on the repository. This is the right channel for an incorrect code sample, a misleading explanation, a broken page, an accessibility problem, or a request for a pattern that is not yet covered.

github.com/negirox07/PatternGuru/issues

Including the pattern name, the language tab you were on, and your browser makes a bug far quicker to reproduce.

Contribute directly

Pull requests are welcome, particularly for additional language examples and clearer explanations.

github.com/negirox07/PatternGuru

Privacy and data questions

PatternGuru holds no personal data on any server — everything you create stays in your own browser, as described in the privacy policy. If something in that policy is unclear, raise a GitHub issue and it will be answered there.

Advertising

Ads on this site are served by Google AdSense and are not sold or reviewed directly. To change how ads are personalised for you, use Google Ads Settings. A specific ad that appears to violate policy can be reported to Google through the information icon on the ad itself.

Response time

This is a side project, not a staffed service. Expect a reply within a few days rather than a few hours.
